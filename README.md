**Skills:**
- Unity Engine (2D/3D)
- Phaser.js for browser-based games
- PixiJS + pixi3d and Babylon.js for 3D browser games
- VR with OpenXR
- C# scripting (mechanics, input, UI, AI behavior)
- JavaScript game development (Vite, GLB/glTF models, Web Audio)

**Projects:**
- 🏰 **[Void Rush](https://github.com/FluffyCrunch/Pixi)** — A 3D tower defense game built twice on the same game data: once with **PixiJS + pixi3d** (with a custom GLB loader) and once with **Babylon.js**. Place Frost, Laser, Cannon, Tesla and Spike Trap towers, unlock branching upgrades, manage your gold economy, and survive escalating waves with boss encounters across multiple difficulties. Uses Kenney Tower Defense Kit 3D assets. **[▶️ Play it live](https://voidrushpixi.netlify.app/)**
- 🍎 **[Apple Catcher](https://github.com/FluffyCrunch/Phaser/tree/main/AppleCatcher)** — A fun browser-based arcade game built with Phaser.js. Catch falling apples with a basket in this 30-second challenge! Features smooth physics, particle effects, sound effects, and real-time scoring.
- 🕹️ **[Flappy Bird](https://github.com/Fluffycrunch/Unity-Game/tree/main/Flappy_Bird)** — Classic Flappy Bird game recreated in Unity with C#. Features smooth gameplay mechanics, score system, and obstacle generation.
